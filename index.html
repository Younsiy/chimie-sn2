Aide-mémoire NDC (202-SN2-RE) & tableau des Ka

Chapitre 2 — Cinétique chimique
**Vitesse :** $v = -\frac{1}{a}\frac{d[\ce{A}]}{dt} = +\frac{1}{c}\frac{d[\ce{C}]}{dt}$ **Ordre 0 :** $[\ce{A}]_t = -kt + [\ce{A}]_0$ $\qquad t_{1/2} = \frac{[\ce{A}]_0}{2k}$ **Ordre 1 :** $\ln\frac{[\ce{A}]_0}{[\ce{A}]_t} = kt$ $\qquad t_{1/2} = \frac{\ln 2}{k} = \frac{0,693}{k}$ **Ordre 2 :** $\frac{1}{[\ce{A}]_t} = kt + \frac{1}{[\ce{A}]_0}$ $\qquad t_{1/2} = \frac{1}{k[\ce{A}]_0}$ Note NDC (p. 111) : on ne voit pas l'équation d'Arrhenius.
Chapitre 3 — Équilibre chimique
**Tableau obligatoire :** I (initiale) – R (réagit) – E (équilibre). **Relation Kp – Kc :** $K_p = K_c(RT)^{\Delta n}$ avec $R = 8,314\u{kPa·L·mol^{-1}·K^{-1}}$ (ou 0,08206 L·atm·mol^{−1}·K^{−1}). Unité entre parenthèses (NDC p. 140) : $K_p = 10,6$ (en kPa). **Gaz parfaits :** $P = \frac{n}{V}RT = CRT$
Chapitre 4 (4.1 à 4.3.1) — Acides et bases
**Les 6 acides forts :** HCl, HBr, HI, {{HNO3}}, {{HClO4}}, {{H2SO4}} (tableau I – R – F, dissociation à 100 %). $K_e = [\ce{OH-}][\ce{H3O+}] = 1,0\times10^{-14}$ à 25 °C $\qquad \text{pH} = -\log[\ce{H3O+}] \qquad \text{pH} + \text{pOH} = 14,00$ **Acides faibles (I – R – E) :** $C_i - x \approx C_i$ si $\frac{C_i}{K_a} \geq 100$ (Cahier NDC, p. 189). Sinon : formule quadratique. $$x = \frac{-b + \sqrt{b^2 - 4ac}}{2a}$$ **Bases faibles :** $K_b(\ce{NH3}) = 1,8\times10^{-5}$ ; $K_b(\ce{C5H5N}) = 1,7\times10^{-9}$

Formules : Électricité et magnétisme (203-SN2-RE)

Chapitre 5 : condensateurs
$C = \frac{Q}{\Delta V}$ $\qquad C = \frac{\kappa\varepsilon_{0}A}{d}$ (plan) $\qquad E = \frac{\Delta V}{d}$ $U = \frac{1}{2}Q\Delta V = \frac{1}{2}C\Delta V^{2} = \frac{Q^{2}}{2C}$ **Parallèle :** $C_{\text{éq}} = C_{1} + C_{2} + \dots$ (même $\Delta V$) **Série :** $\frac{1}{C_{\text{éq}}} = \frac{1}{C_{1}} + \frac{1}{C_{2}} + \dots$ (même $Q$)
Chapitre 6 : courant électrique
$i = \frac{dq}{dt}$ $\qquad i = neAv_{d}$ $\qquad J = \frac{i}{A} = nev_{d} = \frac{E}{\rho}$ $R = \frac{\rho\ell}{A}$ $\qquad \Delta V = Ri$ $\rho = \rho_{0}[1 + \alpha(T - T_{0})]$ $\qquad R = R_{0}[1 + \alpha(T - T_{0})]$ $P = \Delta V i = Ri^{2} = \frac{\Delta V^{2}}{R}$
Chapitre 7 : circuits
**Nœud :** $\sum i_{\text{entre}} = \sum i_{\text{sort}}$ $\qquad$ **Maille :** $\sum\Delta V = 0$ **Série :** $R_{\text{éq}} = R_{1} + R_{2} + \dots$ **Parallèle :** $\frac{1}{R_{\text{éq}}} = \frac{1}{R_{1}} + \frac{1}{R_{2}} + \dots$ **Pile réelle :** $\Delta V = ℰ - ir$ $\qquad P_{ℰ} = ℰ i$ $\qquad P_{r} = i^{2}r$
Chapitre 7 : circuits RC
$\tau = RC$ $\qquad Q_{m} = Cℰ$ $\qquad i_{m} = \frac{ℰ}{R}$ **Charge :** $Q = Q_{m}(1 - e^{-t/\tau})$ $\qquad i = i_{m}e^{-t/\tau}$ **Décharge :** $Q = Q_{0}e^{-t/\tau}$ $\qquad i = \frac{Q_{0}}{\tau}e^{-t/\tau}$ $t = 0$ : $C$ vide agit comme un fil. $t \to \infty$ : $C$ agit comme un circuit ouvert.

Ces quatre encadrés sont un résumé des chapitres 5 à 7. Ils ne sont pas sur l'aide-mémoire ci-dessous.

Aide-mémoire du cours (formules_A26)
Constantes et valeurs utiles
$g = 9,81\u{N/kg}$ $\qquad N_{A} = 6,022\times10^{-23}$ (écrit ainsi sur la feuille ; la valeur usuelle est $6,022\times10^{23}$) $\qquad c = 3,00\times10^{8}\u{m/s}$ $\varepsilon_{0} = 8,854\times10^{-12}\u{C^{2}/(N·m^{2})}$ $\qquad e = 1,602\times10^{-19}\u{C}$ $\qquad k = \frac{1}{4\pi\varepsilon_{0}} = 8,9876\times10^{9}\u{N·m^{2}/C^{2}}$ $m_{e} = 9,1094\times10^{-31}\u{kg}$ $\qquad m_{p} = 1,6726\times10^{-27}\u{kg}$ $\qquad m_{n} = 1,6749\times10^{-27}\u{kg}$ $\qquad \mu_{0} = 4\pi\times10^{-7}\u{T·m/A}$
Mécanique
$\sum\vec{F} = m\vec{a}$ $\qquad \vec{v} = \frac{d\vec{r}}{dt}$ $\qquad \vec{a} = \frac{d\vec{v}}{dt} = \frac{d^{2}\vec{r}}{dt^{2}}$ $\qquad a_{c} = \frac{v^{2}}{r}$ $v_{x} = v_{0x} + a_{x}t$ $\qquad v_{x}^{2} = v_{0x}^{2} + 2a_{x}(x - x_{0})$ $x = x_{0} + v_{x}t + \frac{1}{2}a_{x}t^{2}$ $\qquad x = x_{0} + \left(\frac{v_{0x} + v_{x}}{2}\right)t$ $E = K + U$ $\qquad \Delta K + \Delta U = W_{nc} + W_{ext}$ $\qquad K = \frac{1}{2}mv^{2}$ $\qquad W_{c} = -\Delta U$ $W = \int\vec{F}\cdot d\vec{s}$ $\qquad W = \vec{F}\cdot\Delta\vec{s}$ $\qquad P = \frac{dE}{dt}$ $\qquad P_{\text{moy}} = \frac{\Delta E}{\Delta t}$
Vecteurs
$\vec{A}\cdot\vec{B} = A_{x}B_{x} + A_{y}B_{y} + A_{z}B_{z} = |\vec{A}||\vec{B}|\cos\theta$ $|\vec{A}\times\vec{B}| = |\vec{A}||\vec{B}|\sin\theta$ $\vec{A}\times\vec{B} = (A_{y}B_{z} - A_{z}B_{y})\vec{i} + (A_{z}B_{x} - A_{x}B_{z})\vec{j} + (A_{x}B_{y} - A_{y}B_{x})\vec{k}$
Intégrales
$\int ax^{n}\,dx = a\frac{x^{n+1}}{n+1}$ $(n \neq -1)$ $\qquad \int\frac{dx}{x} = \ln|x|$ $\qquad \int e^{ax}\,dx = \frac{1}{a}e^{ax}$ $\int\frac{dx}{(a + bx)^{2}} = -\frac{1}{b(a + bx)}$ $\qquad \int\sin(ax)\,dx = -\frac{1}{a}\cos(ax)$ $\qquad \int\cos(ax)\,dx = \frac{1}{a}\sin(ax)$ $\int\frac{dx}{\sqrt{x^{2} + a^{2}}} = \ln\left|x + \sqrt{x^{2} + a^{2}}\right|$ $\int\frac{dx}{(x^{2} + a^{2})^{3/2}} = \frac{x}{a^{2}\sqrt{x^{2} + a^{2}}}$ $\qquad \int\frac{x\,dx}{(x^{2} + a^{2})^{3/2}} = -\frac{1}{\sqrt{x^{2} + a^{2}}}$
Électrostatique
$\lambda = \frac{dq}{dL}$ $\qquad \sigma = \frac{dq}{dA}$ $\qquad \rho = \frac{dq}{dV}$ $\vec{F}_{12} = k\frac{q_{1}q_{2}}{r_{12}^{2}}\vec{u}_{12}$ $\qquad \vec{u}_{12} = \frac{\vec{r}_{12}}{r_{12}} = \frac{\vec{r}_{1} - \vec{r}_{2}}{r_{12}}$ $\qquad \vec{F}_{e} = q\vec{E}$ $\vec{E} = \sum_{i=1}^{N}k\frac{q_{i}}{r_{i}^{2}}\vec{u}_{ri}$ $\qquad \vec{E} = \int k\frac{dq}{r^{2}}\vec{u}_{r}$ $\vec{E} = \frac{\sigma}{2\varepsilon_{0}}\vec{u}_{n}$ $\qquad \vec{E} = \frac{|\sigma|}{\varepsilon_{0}}\vec{u}_{-+}$ $U_{e} = \sum_{i<j}^{N}k\frac{q_{i}q_{j}}{r_{ij}}$ $\qquad \Delta U_{e} = q\Delta V$ $\Delta V = V_{b} - V_{a} = -\int_{a}^{b}\vec{E}\cdot d\vec{s}$ $\qquad V = \sum_{i=1}^{N}\frac{kq_{i}}{r_{i}}$ $\qquad V = k\int\frac{dq}{r}$ $\vec{E} = -\left(\frac{\partial V}{\partial x}\vec{i} + \frac{\partial V}{\partial y}\vec{j} + \frac{\partial V}{\partial z}\vec{k}\right)$
